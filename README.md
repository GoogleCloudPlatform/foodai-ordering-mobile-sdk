# foodai-ordering-mobile-sdk

The foodai-ordering-mobile-sdk helps mobile apps integrate a Food Ordering AI Agent using Google Cloud Services. See [these docs](https://docs.cloud.google.com/food-ai/ordering-integration) for how to set up a multimodal ordering experience using the Food Ordering Streaming API.

This SDK is designed to be used with Google Cloud services, including the Food Ordering AI Agent. By using this SDK, you agree to comply with the: [Google Cloud Platform Terms of Service](https://cloud.google.com/terms/).
